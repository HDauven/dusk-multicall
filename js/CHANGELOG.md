# Changelog

All notable changes to this package are listed here. It follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and [Semantic Versioning](https://semver.org/).

## [0.1.0]

### Added

- `createMulticallFetch`: a `fetch` that sends the contract reads of one task as one query
- `aggregate`: a list of reads as one query
- `/codec`: the `aggregate` envelope and reply, encoded and decoded without a data driver
